# SkillFarm — Final V7

V7 is a UX/product-polish pass on top of V6. It keeps the client-required workflows and adds clearer discovery, stronger information hierarchy, and smoother task guidance.

## Added
- Learner home hero content explaining the value and next step.
- Horizontal category shortcuts that turn a tap into a search.
- Course cards now end with a clear View course action.
- Provider dashboard attention card for pending requests / missing upcoming batches.
- Registration timeline copy is more human and action-oriented.
- Existing V6 smart filters, next-batch previews, status summaries, multi-batch workflow, waitlist, approval flow, PDF/Excel export, reviews, organisation gallery, and security migrations retained.

## Product principle
No fake metrics, no unnecessary AI/chat/gamification/payment features. The polish is focused on reducing hesitation and making the next action obvious.
