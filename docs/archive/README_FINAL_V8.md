# SkillFarm V8 — UX + Performance Polish

V8 builds on the client-complete V7 and adds focused product polish without changing the core client workflow.

## Added
- Persistent Saved Courses / bookmarks.
- Recently Viewed courses (last 12).
- Course comparison for up to 3 courses.
- Compare controls on course cards and a dedicated comparison screen.
- Save control on course cards and course detail.
- Learner Saved tab with saved + recent discovery.
- Skeleton loading component for future list/loading states.
- Existing deferred local search retained for responsive typing.
- Existing batched next-batch queries retained to avoid N+1 card requests.
- Existing filters, batch clarity, registration timeline, provider attention dashboard, reviews, gallery, PDF/Excel export and security/RLS retained.

## Product principles
- No fake data or fake analytics.
- No payment, chatbot, gamification or unrelated features.
- Keep the main journey: Discover → Understand → Choose batch → Request seat → Track request.
