# SkillFarm – fixes for client-reported errors (2026-10-09)

## 1. "Could not approve – stack depth limit exceeded"
**Cause:** endless trigger loop (`registrations → batches → courses → batches → …`) introduced by
`20261011_learning_partner_event_sync.sql`.
**Fix:** run `supabase/migrations/20261012_fix_trigger_loop_restore_razorpay.sql` once in Supabase → SQL Editor.

## 2. Razorpay payment step missing
**Cause:** `20261010_direct_seat_booking.sql` replaced `book_seat()` with an instant-confirm version,
overwriting the payment-aware one. The same 20261012 file restores it
(paid course → pending → Razorpay → registered; free course → registered).
Also confirm: course **Fee > 0**, Edge Functions `create-razorpay-payment` + `razorpay-webhook` deployed,
secrets `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET`, `RAZORPAY_WEBHOOK_SECRET` set (see RAZORPAY_BOOKING_SETUP.md).

## 3. Material / course ID does not open (blank white page)
- Course-ID check in the materials screen was too strict and could reject valid IDs → relaxed.
- "Open" on Android used a raw `file://` / signed-URL browser open (blank page). It now downloads to cache and opens
  with the system viewer (expo-sharing); web still opens the signed URL.
- App start could sit on the spinner forever if network/role lookup stalled → 8 s fail-safe added.

## 4. Google sign-in `DEVELOPER_ERROR`
**Cause (config, not code):** `google-services.json` has only the Web client (type 3). There is no Android client
(type 1) because no SHA-1 is registered for `com.skillfarm.app`.
**Fix:**
1. `npx eas credentials -p android` → copy SHA-1 + SHA-256 of the keystore used by the build profile.
   (If the app is on Play Store with Play App Signing, also copy the *App signing key* SHA-1 from Play Console → App integrity.)
2. Firebase Console → project `skillfarm-bf0ab` → Project settings → Android app `com.skillfarm.app` → Add fingerprint (each SHA).
3. Download the new `google-services.json`, replace the one in project root (it will now contain a `client_type: 1` entry).
4. Supabase → Auth → Providers → Google: add the Web client ID `334322665437-cgfc4tejd9lnb9qc40td4mqapdu1ff49.apps.googleusercontent.com` under *Authorized Client IDs*.
5. Rebuild the APK/AAB (`npx eas build -p android`). Not testable in Expo Go.

Version bumped to 1.7.1 (Android versionCode 26).
